How to install the Chrome Extension in 30 seconds

Direct ZIP · No store fee
1

Download & unzip the extension

Click Add to Chrome Extension above to download Little-Later-Chrome-Extension.zip, then double-click the downloaded ZIP file so it extracts into a folder.

2

Open Chrome Extensions & enable Developer mode

Paste the extensions address below into a new browser tab and switch Developer mode ON in the top-right corner.

3

Click "Load unpacked" & select the folder

Click Load unpacked in the top-left corner, choose the unzipped Little-Later-Chrome-Extension folder, and pin Little Later from the puzzle icon in your toolbar.
