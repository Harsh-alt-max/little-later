# Little Later — Website (v3, minimal marketing page)

Minimal sales page. No workable app UI, no extra text — headline, download,
3 demo screens, download tutorial, 6-step how-to-use tutorial.

## Files
- `index.html` + `images/` (upload together)
- `images/mascot.png` — mascot logo cropped from the reminder screenshot
  (blue creature + yellow star, in its light-blue circle), used in nav, hero,
  section heads, closing CTA and footer
- `images/` — `welcome.jpg`, `home.jpg`, `folders.jpg`, `reel.jpg`,
  `share.jpg`, `apps.jpg`, `choose-folder.jpg`, `choose-time.jpg`,
  `reminder.jpg` (step 6: how a reminder looks)
- `little-later-tokens.css`, `design-tokens.json`, `BRAND-GUIDELINES.md`, `icons/`

## Publish on GitHub Pages
1. Harsh creates a repo under Harsh-alt-max.
2. Upload the whole folder to `main`, at the root.
3. Settings → Pages → Deploy from a branch → `main` / root → Save.
4. Live in ~1–2 min at `https://harsh-alt-max/<repo-name>.github.io/`.
